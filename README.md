# Math Arena

A web-based math practice tool built for tutoring fundamentals to students.

## Features

- **Quiz Mode** -- Timed arithmetic with mixed operations (+, -, x, /), configurable question counts (25/50/100)
- **Times Tables Mode** -- Practice specific times tables (1-12 or all), sequential or random order
- **Fractions Mode** -- Simplify, add, subtract, multiply, divide fractions, plus LCM and HCF exercises with visual stacked fraction display
- **Scientific Calculator** -- Full Sharp EL-W535HT simulator with WriteView display, trig/log/stats, STAT mode, DRILL mode, memory functions, and keyboard support

## Tech

Pure HTML, CSS, and JavaScript -- no frameworks, no build tools. Designed to run as a static site on GitHub Pages.
